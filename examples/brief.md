# 示例任务与数据说明

本目录全部数据为人为构造的模拟数据，SKU不对应真实商品或账户。它是自定义汇总表，不是亚马逊原生报表格式，也不是skill要求所有用户遵守的输入模板。

## 示例用户请求

> 我想知道这两个商品最近两周销售和贡献利润为何下降，下周应先检查什么。请结合销售与广告数据给出PDF报告。没有库存、价格调整或促销日志；不要直接替我改预算。

## 已知背景

- 站点US，币种USD，两期均为完整14天：2026-09-01至09-14、2026-09-15至09-28。
- 每行是一个SKU在一个期间的汇总；`period + marketplace + sku`为本示例唯一键。
- 两个SKU互斥且构成完整的示例业务范围；两期均有同样的商品集合。
- `sessions`为访问会话数；`units`为订购件数；`orders`为订单数，不能相互替代。
- `sales`为本示例商品销售额；为简化复算，假定没有税费、退款和折扣差异。
- 广告数据假定来自同一种广告类型、同一成熟归因窗口，`ad_sales`为该示例范围内的归因销售，不代表增量销售。
- 成本列均为正的费用金额：采购成本、销售佣金、履约费用、其他可变成本。其他可变成本为示例约定的物流分摊，不含广告；`ad_spend`单独扣除。
- 贡献利润＝销售额－四类可变成本－广告花费。未包含固定管理费用、税务和未列明成本，因此不称净利润。
- 没有广告订单、搜索词、可售库存和外部市场数据，不能计算广告订单转化率、判断搜索词原因或证明缺货。

## 复现

```bash
python scripts/build_example.py --output-dir work/example
```

脚本读取固定的模拟CSV，核对关键字段后计算汇总、变化和报告内容。输出`sample-report.json`与`sample-report.pdf`。它是示例构建器，不是面向任意用户报表的自动诊断工具。实际分析需要按用户数据建立字段映射，并选择适用方法。

仓库附带生成好的报告，可直接查看。修改这份模拟数据的业务含义后，需要同步检查报告解释与假设，不能只重算数字。
