# 按问题选择方法

方法可以组合，以下不是固定报告模块。

| 用户要做的判断 | 适用方法 | 关键条件 |
| --- | --- | --- |
| 发生了什么变化 | 完整期间对比、日／周趋势、变化贡献 | 可比口径，区分长期趋势与单日波动 |
| 为什么变化 | 候选解释检验、恒等分解、事件对照、分层比较 | 描述性关联与因果结论分开 |
| 先处理什么 | 按损益或机会规模排序，同时保留可控性、证据与成本 | 不以任意综合分数替代真实约束 |
| 哪个对象更值得投入 | 同阶段、同口径比较；边际贡献与容量判断 | 可比成本、样本量、库存和可扩展性 |
| 某个市场是否值得进入 | 样本覆盖、价格分布、需求趋势、竞争与单位经济情景 | 估算数据与实测分开，样本不冒充整个市场 |
| 某项调整是否有效 | 随机试验或有条件的对照分析，前后对比作为较弱证据 | 分配方式、同期变化、样本量与指标预先定义 |
| 接下来可能怎样 | 情景区间、敏感性分析；足够历史下的预测与回测 | 假设可见，预测不冒充事实，短历史不推断季节性 |
| 买家在反馈什么 | 文本编码、主题频率、原文例证与分层 | 样本偏差、重复评论、主题口径、引用隐私 |

## 可用的拆解方式

**变化贡献**：对每个互斥分组计算本期减基期，核对各组变化之和等于整体变化。数据不完整时先报告未归属部分。

**两因子分解**：若Y＝A×B，可用中点分解：A贡献＝(A1－A0)×(B1＋B0)／2，B贡献＝(B1－B0)×(A1＋A0)／2。两者之和等于Y1－Y0。说明这是会计式分解，不是因果效应；多因子可选择明确的分解顺序或方法，不能将不同方法的贡献混合。

**集中度与分布**：看前若干商品或词的份额、分位数和尾部，避免仅报告平均值。样本份额注明样本分母。

**利润敏感性**：在销售、退货、采购、物流和广告成本的可见假设下计算不同情景。缺少成本的项目列为空缺或待补，不默认零。

**文本主题**：先形成可解释的主题定义，允许一条反馈多标签；检查否定、反讽和使用语境。将主题次数与用户人数区分，原文例证脱敏。

## 提问示例

- 用户问销售为何下降：优先确认比较范围及已知运营变化，再从整体和贡献展开，不先要求完整利润成本。
- 用户问竞品机会：优先确认目标市场与筛选目标，再检查样本代表性，不要求提供自己店铺广告权限。
- 用户问预算调整：需要目标、利润或预算约束，以及同口径归因表现；无法判断增量时给验证方案。
- 用户只要数据概览：描述结构与关键分布，标出异常和可继续研究的问题，不强制生成正式战略建议。
