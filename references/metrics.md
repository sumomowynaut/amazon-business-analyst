# 指标定义与使用条件

以下为计算约定；实际字段以本次报告的来源定义为准。遇到不同口径，保留差异并说明，而不是把数据强行改成同一指标。

## 流量、订单与销售

| 指标 | 计算或含义 | 注意事项 |
| --- | --- | --- |
| 订单量 | 符合范围的订单数 | 与订单项目数、订购件数区分；退款和取消是否剔除须明确 |
| 销售件数 | 商品订购或售出件数 | 说明按订购、发货还是结算统计 |
| 每单销售额 | 同范围销售额 ÷ 订单数 | 一单多件时不能用件数代替订单数 |
| 每件销售额 | 同范围销售额 ÷ 件数 | 不是标价，折扣、退款及税费口径会影响数值 |
| Unit Session Percentage | 按对应业务报表定义，通常为订购件数 ÷ Sessions | 每会话可购买多件，数值可能超过100%；不等同于买家购买概率 |
| 订单转化率 | 同范围订单数 ÷ 对应流量分母 | 必须写清分母是Sessions、点击还是其他单位 |
| 购物车赢得率 | 使用报表提供的Featured Offer相关指标及口径 | 不能用缺货天数或销售占比替代 |

只有在粒度、周期、商品和定义相符时，才使用“销售额＝Sessions × 件数／Sessions × 销售额／件数”作为描述性恒等分解。零分母时无法分解；该恒等式不证明流量或转化的因果作用。

## 广告

| 指标 | 计算 | 使用条件 |
| --- | --- | --- |
| CTR | 点击数 ÷ 展示数 | 同广告范围；展示为零时不可计算 |
| CPC | 广告花费 ÷ 点击数 | 点击为零时不可计算 |
| 广告点击转化率 | 点击归因订单数 ÷ 点击数 | 确认订单来自点击归因；不要混入浏览归因订单 |
| CPA | 广告花费 ÷ 广告归因订单数 | 写明归因类型；没有订单时报告花费及零订单，不显示CPA为零 |
| ROAS | 广告归因销售额 ÷ 广告花费 | 收入回报倍数，不是利润回报；花费为零时不可计算 |
| ACOS | 广告花费 ÷ 广告归因销售额 | 销售为零时不可计算，不能显示为0%或任意巨大有限值 |
| TACOS | 广告花费 ÷ 同范围总销售额 | 商品、站点、币种、期间及销售口径需要对齐 |
| ROI | 明确定义的净收益 ÷ 对应投入 | 说明收益扣除了哪些成本及投入范围，不能与ROAS混称 |

归因销售包括平台归因规则下分配的销售，不直接等于增量销售。推广商品和被购买商品可能不同；各广告产品归因销售直接相加可能存在重叠。没有可对账的同口径证据，不用“总销售－广告归因销售”命名自然销售。

在单一商品、归因销售与成本口径可比、广告前贡献利润率定义完整的简化情景下，盈亏平衡ACOS可用广告前贡献利润率近似。必须注明该条件，不把它当作全店通用阈值，也不据此证明广告增量盈利。

## 利润、现金与库存

- **净销售额**：按约定从销售中扣除折扣、退款等；税费是否包含单列说明。
- **贡献利润**：净销售额减去本次定义的可变成本。列明采购、佣金、履约、物流、广告、退货等实际纳入项。固定费用未覆盖时不能称净利润。
- **贡献利润率**：贡献利润／同口径净销售额。负数有效；分母为零时不计算。
- **净利润**：只有相关成本和分摊范围足够完整时使用；否则交付已覆盖成本下的利润，并列出缺失项。
- **结算到账额**：是现金口径，受结算周期、预留及历史调整影响，不能替代销售额或利润。
- **库存覆盖天数**：可售库存／预计日需求。需求为零时不能返回零天；在售期间的销量也未必代表缺货期间潜在需求。
- **补货量**：在明确服务水平、提前期、目标覆盖期和安全库存的前提下，按需求预测扣减可用库存位置；在途和预留不能重复计入。缺少这些条件只给情景，不给确定采购指令。
- **退货或退款率**：分别定义件数、订单或金额分母。事件发生期的退款与同期新订单可能不属于同一队列。

## 汇总与比较

- 汇总比率＝汇总分子／汇总分母；不要平均商品ACOS、转化率或利润率。
- 同比、环比须说明期间。基期为零时相对增幅未定义，显示绝对变化；涉及负基期利润时优先报告金额变化。
- 由10%到12%为增加2个百分点，也可表述相对增加20%，两者不能混用。
- 金额计算保留足够精度，展示时才四舍五入；不要对已舍入比例再次计算。
- 第三方销量估算、关键词搜索量与流量得分保留原始单位；得分不能作为访客数、点击数或销售分母。
- 市场份额的分母若只是用户给出的竞品集合，命名为样本内份额。价格、BSR或关键词排名不直接转换为真实销量。
