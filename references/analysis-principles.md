# 判断与建议的依据

## 比较条件

先核对业务范围，再解释差异。等长时间窗口仍可能受到星期结构、季节、大促、节假日、价格、缺货、变体调整与广告归因成熟度影响。缺少对应历史时保留限制，不虚构季节校正或行业平均值。

新商品测试、成熟商品盈利和库存清理可能有不同目标。ACOS、增长率和库存天数没有适用于所有商品的固定合格线。目标来自用户、可靠历史或明确标注的情景假设。

## 证据层级

- **证据支持**：数据直接显示的数值或经过明确计算的结果，附来源与比较范围。
- **待验证解释**：一种与数据相容但未排除其他原因的解释，说明还需要什么验证。
- **数据不足**：缺少关键字段、覆盖或可比性，无法可靠判断。指出补充哪项数据可以改变结论。

一个段落可以同时包含事实和推断，但两者要分开。比如“缺货天数增加”是事实，“销量全部由缺货导致”仍需要证据。

## 样本与不确定性

不为所有指标规定统一最低样本量。考虑事件稀少程度、波动、观察期和决策成本；高波动或零转化小样本不直接支持大幅扩量或停止投放。

需要置信区间或显著性检验时说明方法与假设。点击并不总是独立买家，重复用户、时间相关和多重比较会影响判断。显著性不能替代商业收益判断，也不能从观察性前后对比得到随机试验的因果结论。

评论主题统计的分母是实际分析的有效评论，不是全部买家。一个评论包含多个主题时，主题占比之和可超过100%；去重、抽样和编码规则需要可复查。对仅有文本的任务不强制生成财务指标。

## 从整体到贡献

先确定整体发生了什么，再看变化由哪些商品、词、活动或分组贡献。贡献既可能为正也可能为负；总变化接近零时，贡献率可能极不稳定，优先展示金额或件数变化。

检查组合变化：整体转化率下降可能来自低转化商品占比上升，即使每个商品自身转化率都没有下降。价格带、变体结构和站点占比也可能产生类似结果。

## 反证与动作

对每项主要建议回答：

1. 什么证据支持采取这个动作？
2. 哪个其他原因若成立会使建议失效？
3. 还有哪些约束会改变动作，例如库存、毛利、补货提前期或品牌目标？
4. 用什么指标、何时复查？什么条件下调整或停止？

没有历史剂量反应或试验依据时，不承诺增加预算后的线性销量增长。试验幅度、观察期和停止条件可以作为待商定假设，但不能伪装成数据计算结果。

分析报告中的建议不等于获得执行权限。本skill不修改预算、报价、商品信息或采购计划。
