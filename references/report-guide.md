# 报告组织与表达

默认正式交付为PDF，正文包含必要图表。篇幅以问题复杂度和证据量决定；不预设固定页数或每个业务模块都必须出现。

## 内容骨架

1. **决策摘要**：要回答的问题、最重要的发现、建议先做什么、哪些判断尚未成立。先写结论，再给支持它的证据。
2. **范围与关键指标**：时间、对象、站点、币种、来源，以及本次确实使用的关键指标。展示基期、本期、绝对差和适用时的相对差。
3. **问题分析**：按实际问题安排章节。每节包含判断、证据、图表及可能的其他解释。简单任务可合并章节。
4. **行动建议**：说明动作对象、证据、约束、优先顺序与复查方式。没有负责人信息时不虚构人员分工。
5. **局限与待补数据**：说明限制影响哪个结论，以及补充信息后能做什么判断。
6. **数据与方法说明**：来源文件和工作表、字段、筛选范围、公式、清洗与关联规则、数据截止时间及假设。

这里的数据来源指用户提供的材料及另行授权使用的来源，不要求给通用分析方法添加作者归属。

## 图表选择

- 趋势使用折线图；类别比较使用条形图；变化贡献使用有正负方向的条形或瀑布图；分布使用直方或箱线图；关系使用散点图。
- 图表标题写具体指标和范围，标明坐标、单位、期间和数据来源。金额注明币种。
- 图表需要解释一项判断；没有可量化数据时可用证据表，不制造装饰性数字。
- 条形图通常从零开始；需要截断轴时明确标记。不同量纲避免共用同一轴，双轴图需要充分解释。
- 不把数据缺失画成零，不用3D效果改变比例感知。小样本、估算和预测在图注中标明。

## 建议的表达

采用“事实 → 解释边界 → 行动”的顺序。举例数字需标注为模拟；实际分析的数字必须能复算。

不写空泛的“加强运营”“优化广告”。具体指出要核查或调整的对象和复查指标。没有证据支持的调整百分比、收益承诺、行业均值和硬性阈值不写成事实。

## 交付检查

- 摘要、表格、图表及计算明细对账，四舍五入差异说明清楚。
- 来源能定位到文件、工作表、字段和时间；无需暴露完整本机路径或客户信息。
- 文字区分事实、解释和缺口；关键结论包含可能失效的条件。
- PDF可打开、文字可检索；中文字体完整，表头重现，长表可跨页，图表及脚注未裁切。
- 交付文件名含任务或期间信息，避免覆盖用户源文件。保留可复现计算和报告内容，方便后续更新。
