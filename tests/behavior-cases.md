# 行为验收用例

以下用例用于检查 skill 是否按预期工作。每条给出输入、应当出现的判断、以及不该出现的结论。人工执行，不依赖自动评分。

## 用例 1：销售下滑，只有汇总表

**输入**：两期各 14 天的商品汇总，含 Sessions、件数、销售额、广告花费与归因销售；无库存、价格和促销日志。
**应当**：确认整体变化，按商品拆出贡献，指出流量与转化同时变化，把缺货、调价、促销列为待验证解释并说明需要什么记录。
**不该**：直接断言"广告导致销售下滑"；用总销售减归因销售得到"自然销售"；给出未经测算的预算下调比例。

## 用例 2：广告报表，字段含中文表头

**输入**：第三方工具导出的活动、广告组、搜索词三层数据，表头为中文，含合计行。
**应当**：识别三层粒度不可相加；剔除合计行并说明；由汇总分子分母重算 ACOS 而不是平均各活动 ACOS；报告搜索词覆盖缺口。
**不该**：把三层花费加总；把搜索词明细合计当作广告总花费；对零归因销售的活动显示 0% 或极大 ACOS。

## 用例 3：利润表缺成本

**输入**：销售额、广告花费、佣金，缺采购和物流成本。
**应当**：只报告已覆盖成本下的差额，明确列出缺失项，不称净利润；给出补齐成本后能回答什么问题。
**不该**：把"销售额－广告费"称为利润或毛利；默认缺失成本为零。

## 用例 4：竞品导出，估算数据

**输入**：某站点 30 个竞品的估算销量、价格、评论数与关键词排名。
**应当**：声明是样本内比较，用"样本内份额"而非市场份额；比较价格分布与集中度；把排名和估算销量保留原始单位。
**不该**：称其为类目规模；把排名换算成销量；由低评论数直接推断"容易进入"。

## 用例 5：评论文本

**输入**：120 条评论，允许一条多主题。
**应当**：说明主题占比之和可超过 100%，展示样本内提及比例、编码规则与脱敏原文；区分提及次数与人数。
**不该**：把 30/120 称为"所有买家的尺寸不满意率"。

## 用例 6：数据不完整但问题仍可部分回答

**输入**：只有最近 7 天数据，用户问同比。
**应当**：说明无法做同比，改为回答这 7 天内的结构与异常；给出最少需要补哪些天。
**不该**：用 7 天冒充月度结论；编造行业均值或季节性校正。

## 用例 7：报告交付

**输入**：任一完成的分析。
**应当**：PDF 可打开、中文可检索、表头在跨页时重现；每个关键数字能追溯到文件、字段与筛选范围；摘要先给结论。
**不该**：图表数值与正文不一致；把缺失画成零；把 Markdown 文件称为 PDF。
